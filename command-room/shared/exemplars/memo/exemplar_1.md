# Memo — structural exemplar (kind: memo)

> STRUCTURE CONTRACT — annotations are the exemplar; sample lines are
> synthetic. Layout only: the exec header, decision-order check, and ask cap
> are contract-enforced at the render chokepoint (contract > exemplar >
> default).
>
> - Header: VERDICT-only lead (memo is an eyebrow-excluded kind — no
>   CHANGED / DECIDE / NEEDED lines). Verdict = the memo's single conclusion.
> - Target length by type: decision doc 300–600 words · scope 400–800 ·
>   strategy 600–1000 · position paper 500–900 · project update 250–500.
>   No paragraph over 150 words. Prose, not bullet walls.
> - Ordering rule (enforced): the Decision / Recommendation / Thesis section
>   sits in the first three sections, always before analysis.
> - Visuals: any data-bearing section renders as a table / matrix / tile band,
>   never a bullet wall (a tradeoffs table is the common case).
> - Ask close: mandatory "The ask" close, 0–3 reader-actions derived from the
>   memo type ("Ratify by [date]" for a decision doc).
