# Command Room - PSBP custom skills

This folder is PSBP's private custom plugin, layered on top of the core command-room plugin.

- Core updates never touch this folder.
- To replace a stock skill: add the custom version here, then list the core skill's name in _chalette/overrides.json at the repo root.
- Add each custom skill as skills/<skill-name>/SKILL.md.

Empty for now. Not yet listed in marketplace.json - it gets added there the moment PSBP has a real custom skill.
