# Command Room — PSBP

Private GitHub marketplace for the Command Room plugin, dedicated to PSBP. Every new release ships to this repo — install once, then use Cowork's Update button to pull new versions.

## Install

1. In Cowork, link GitHub: Customize -> Connectors -> GitHub -> connect.
2. Customize -> Personal plugins -> "+" -> Add marketplace.
3. URL: `https://github.com/chalettehq/CommandRoomPSBP` -> Sync.
4. Install the Command Room plugin from the marketplace it just added.

## Updates

When a new version ships:

1. Customize -> Personal plugins -> Command room.
2. Click **Check for updates**, then click **Update** when the button activates.

That's it — no need to re-add the marketplace.

## Current version

See `command-room/.claude-plugin/plugin.json` (`version` field) for the current release. Full version history in `command-room/CHANGELOG.md`.
